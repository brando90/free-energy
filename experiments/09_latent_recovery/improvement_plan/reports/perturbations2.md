## 0. Shared pipeline mechanics (applies to all families)

- **Dataset** (`build_dataset.py`): PrOntoQA-OOD `*ProofsOnly*.json` (14 files) + `*Composed*.json` (9 files); test + in-context examples, deduped by question text, requires ≥4 derived (entity-subject) steps, cap 500 → `data/pilot.jsonl`.
- **Trace source**: the model's OWN greedy CoT on solved instances (`results/gold/rollouts.jsonl`), split on sentence boundaries. EXPB is the exception: it perturbs the *dataset* gold proof, not a model rollout.
- **Injection sites**: entity-subject sentences (subject = capitalized name matching sentence 0's first word; EXPC uses `parse_fact` instead of first-word heuristic); drop the first (premise restatement) and last (conclusion); need ≥3 intermediates; `early` = first, `mid` = middle, `late` = last intermediate.
- **Injection = replacement, not insertion**: prefill is `steps[:si] + [corrupted]` — the corrupted sentence *replaces* the gold step at `si` (exceptions: paraphrase preserves the step's content; EXPB *inserts* a certificate before the replacing falsehood, making its prefix one sentence longer). Continuation is greedy (`do_sample=False`), `max_new=192`, no feedback.
- **World semantics** (`validator.py`): question parsed into cat→cat / cat→(not_)cat / cat→adj(±) rules + entity facts; `closure` = transitive closure over cat→cat with adj/not_cat propagated; `derivable(pred, premises, reach)`. "False" for positive category claims = unentailed under closed-world assumption (CWA); negated entailed claims are false outright.

## 1. Exact construction per family

### Legacy sweep families (`perturb.py`, env `PERT_FAMILY`; constructors in `common.py`)

| Family | Constructor | Template of injected sentence | Selection rule | Truth status |
|---|---|---|---|---|
| **benign paraphrase** | `make_paraphrase(steps, si, idx)` | `"Therefore, / It follows that / Thus, " + steps[si]` (marker cycles with `idx`; lowercases quantifier-initial steps) | restates the gold step verbatim + discourse marker | **true** (same content) |
| **wrong** (`wrong_category`) | pick category from question **not appearing in the gold CoT text** (fallback: any question category), cycle by `idx`; emit `"{Entity} is a {cat}."` | positive entity-category fact | off-gold-path by *lexical* test only | **not audited** — usually false but can be entailed via an alternate path |
| **falsehood** (`make_falsehood`) | like `wrong` but candidate cats filtered by validator: `not derivable(("cat",c), premises, closure)`; asserts the invariant | positive entity-category fact | off-path and provably unentailed | **guaranteed false (CWA)**; = paper's "global falsehood" precursor |
| **distractor** | `make_distractor`: off-path category (question cats minus gold-CoT cats) × an adjective harvested from question `"is (not) ADJ."` sentences; emit `"Every {cat} is {adj}."`, rejecting exact matches to question text | **rule** sentence, quantified | guaranteed *not an actual rule of this question* (string check only) | unaudited; unsupported/unknown |
| **contradiction** | `make_contradiction(steps, prefix_end)`: negate the **most recently established entity fact in the prefix** (regex flip `is a X` ↔ `is not a X`, `is (not) adj`) | negated entity fact | contradicts a sentence *already stated* in the prefix → distance-0, maximal lexical overlap | **false** (negation of established fact) |
| **negstep** (= 1-hop falsehood) | `make_negstep(steps, si)`: negate the gold step at `si` itself | negated entity fact | the gold step is entailed-true so its negation is false; *not yet asserted* in prefix, so textually consistent but refutable in 1 rule application | **guaranteed false, selection-free** |
| **neghop-k** (k=2..5; `results/perturbed_neghop{2..5}`) | `make_neghop(steps, si, k)`: at position `si`, inject the negation of the entity fact the gold chain derives at entity-step index `j+(k-1)` (j = index of si; k=1 ≡ negstep); refuses to target the final conclusion | negated entity fact | falsifying derivation is **k inference hops downstream** of the injection point | **guaranteed false** |

### EXPA (`expa_global_expansion.py`, conditions crossed with early/mid/late, audited-and-fail-closed)
- `global_falsehood` = `make_global_falsehood`: positive `"{Entity} is a {cat}."` with cat drawn from `false_categories` (unentailed under closure from the entity's premises), cycled by `position_index + seed`; run kept **only if audited false at all 3 positions**.
- `benign_paraphrase` = same as legacy paraphrase.
- `one_hop_falsehood` = `make_negstep` on the model's own step; kept only if audited `false`.
- `true_interruption` = `make_true_interruption`: positive `"{Entity} is a {cat}."` where cat is **entailed** for the entity but never asserted on the model's actual proof path; kept only if audited `true`. (True, categorical, off-path, no negation.)
- Gold rollout must be `solved` **and** validator-class `valid_rederivation` before perturbation; every injected statement gets `audit_truth_status` (closed-world for positive categories; open-world "unknown" for negated-unentailed and undecidable adjectives → those rows dropped to audit log, not silently replaced).

### EXPB local-certificate flip (`expb_local_cert_flip.py`)
Unit = (problem, position, falsehood-category) triple; **F** = `make_positive_cat(entity, fcat)` for every globally-false category `fcat`; prefix built from the *dataset* proof `original_proof[:sent_idx]`. Three conditions share question/target/prefix/F exactly (`prompt_sanity` verifies):
- `GLOBAL_BASELINE`: prefix + F.
- `LOCAL_CERTIFICATE`: prefix + **C** + F, C = `"{Entity} is not a {fcat}."` — the direct negation, inserted immediately before F. `locally_falsifies` requires C's negated category to equal F's cat or be closure-reachable from it.
- `IRRELEVANT_CERTIFICATE_CONTROL`: prefix + **C_irrel** + F, C_irrel = `"{Entity} is not a {icat}."` where `icat` is another globally-false category **not reachable from fcat** (so it does not falsify F), chosen to minimize |len(icat)−len(fcat)| — a length-matched, same-template, same-polarity negative sentence.
- Fail-closed audit invariant (`is_fully_audited`): F false, C true, C locally-falsifies-F, C_irrel true, C_irrel does *not* locally falsify F. Certificate char/token deltas logged.

### EXPC polarity control (`expc_polarity_control.py`) — 2×2 locality × polarity, fail-closed (problem kept only if all 4 cells exist at all 3 positions)
"Local" ≡ opposite predicate `directly_derivable` from prefix state (distance ≤1 rule application); audit records `local_rule_distance` = `shortest_rule_distance(opposite, prefix_state, direct_rules)`.
- `LOCAL_FALSE_POSITIVE`: scan prefix category atoms for a **direct rule with negative RHS** (e.g., "Tumpuses are not bright"); inject the opposite positive claim (`"X is bright."`). Category-noun candidates preferred (sort key 0) but in practice **100% attribute template** (see §4).
- `LOCAL_FALSE_NEGATIVE`: negate the gold step at `si`, requiring that positive pred be directly derivable from the prefix (`"X is not a {cat}."`, 100% category template).
- `GLOBAL_FALSE_POSITIVE`: unentailed category with **no negative evidence anywhere** (neither `not_cat` entailed globally nor directly derivable locally) → `"X is a {cat}."`.
- `GLOBAL_FALSE_NEGATIVE`: negate an entailed positive pred at rule distance **≥2** from prefix and not in/adjacent to prefix (mixed templates: 14 `entity_is_not_a_category`, 7 `entity_is_not_attribute`).
- All four audited `false`; token means 4.76 / 8.48 / 7.24 / 7.67 (LFP is systematically shorter — residual length confound, reported).

### matched_pert.py
Not a new family: re-runs **paraphrase vs negstep at mid** with sampled decoding (T=0.8, n=4) so the ρ_func numerator (perturbed) and denominator (null resamples, `results/null`) share a decoding distribution. Matches: same instance, same prefix, same injection point, same decoding params/temperature, same horizon alignment (boundary states at h=1..4 sentences after injection, JSD to the aligned gold state). It does **not** add matching on sentence length, polarity, or template.

## 2. Confound matrix (family × axis)

Legend: ✔ = property present; ✗ = absent; ~ = partial/uncontrolled; **R** column = refutation distance (the intended causal variable). Axes: **Fals** = audited-false; **Neg** = negation token in injected sentence; **LexC** = explicit lexical contradiction/overlap with an already-stated sentence; **Type** = fact (entity) / rule / categorical-vs-attribute; **Path** = on gold derivation path; **Use** = derivationally usable toward goal (or blocks it); **Del** = gold step deleted (replaced); **Style** = surface-style change (discourse marker).

| Family | Fals | Neg | LexC | Type | Path | Use | Del | Style | Refutation distance R |
|---|---|---|---|---|---|---|---|---|---|
| benign paraphrase | ✗ true | ✗ | ✗ (restates) | fact | on | advances | **✗ (only family keeping the step)** | **✔ marker (only family)** | n/a |
| true interruption (EXPA) | ✗ true | ✗ | ✗ | fact, categorical | **off** | inert | ✔ | ✗ | n/a |
| distractor rule | **unaudited** | ✗ | ✗ | **rule** (only non-fact family) | off | inert | ✔ | ✗ | undefined (rules not audited) |
| contradiction | ✔ | ✔ (usually) | **✔ direct clash w/ prefix sentence** | fact | on | blocks | ✔ | ✗ | 0 (stated text) |
| negstep / one-hop falsehood | ✔ | ✔ | ✗ (fact not yet asserted) | fact | on | blocks | ✔ | ✗ | 1 |
| neghop-k (k=2..5) | ✔ | ✔ | ✗ | fact | on (future fact) | blocks later | ✔ | ✗ | k |
| global falsehood | ✔ (CWA only) | **✗ affirmative** | ✗ | fact, categorical | **off** | ~ (may feed distractor rules; "poisoning measurable" subset) | ✔ | ✗ | ∞ / global-only |
| wrong_category (legacy) | ~ | ✗ | ✗ | fact, categorical | off (lexical test) | ~ | ✔ | ✗ | unaudited |

**Axes confounded with R across the primary family contrast (local negstep vs global falsehood):** (1) **negation presence** — every low-R family (contradiction, negstep, neghop) is negative; the only high-R falsehood is affirmative → EXPC's target; (2) **on/off-path relevance** — low-R families negate on-path facts, global falsehood asserts off-path ones; (3) **derivational usability** — negsteps block the needed step, global falsehoods are goal-inert-or-poisoning; (4) **CWA-strength of falsity** — negstep false *outright*, global falsehood false only under closed world; (5) partially **length/template** (EXPC token table). Axes confounded in the *control* contrasts: paraphrase carries the only stylistic marker AND is the only non-deleting family (benign vs. everything is a 2-difference contrast); distractor differs in statement type AND truth-auditability; contradiction adds lexical clash on top of R=0.

## 3. What varies vs. held constant in the three isolation instruments

- **Distance-k (neghop dose-response)** — *varies*: R = k (1..5), i.e., how many rule applications from the prefix state the refuting derivation is. *Holds constant*: falsity guarantee, negation token, template (`entity is not (a) X`), statement type (entity fact), subject entity, injection position, prefix, decoding, step deletion. *Residual confounds*: the negated fact's proximity to the conclusion shrinks as k grows (goal-relevance/usability co-varies with R); larger k restricted to longer chains (instance-composition shift); which category is negated changes with k.
- **EXPB cert-flip** — *varies*: only the one inserted certificate sentence (local-refuting C vs. non-refuting C_irrel vs. none), i.e., flips a *fixed global falsehood* from R=∞ to R=0 while F itself is byte-identical. *Holds constant*: question, target, prefix, F, position, decoding, F's truth status; C vs C_irrel additionally match polarity (both negative), template (`entity is not a X`), and approximately length. *Residual confounds*: C lexically contains F's category (overlap IS the manipulation, but "string-match contradiction" vs "inferential refutability" are not separated — C is distance-0/lexical, not distance-1/rule-mediated); LOCAL/IRREL prefixes are one sentence longer than baseline; C also *derivationally pre-empts* F (asserts ¬F before F).
- **EXPC polarity control** — *varies*: locality (opposite directly derivable from prefix vs. distance ≥2/global-CWA) fully crossed with surface polarity (affirmative vs negated injected sentence). *Holds constant*: audited falsity (all four cells false), position pairing, prompt bytes (SHA-pinned), problem (fail-closed 2×2×3 within-problem). *Not held constant*: statement type — LFP is 100% attribute, LFN 100% not-category, GFP 100% category, GFN mixed — so **polarity × statement-type is aliased within the local row**; token length (4.8 vs 7.2–8.5); n = 7 problems / 21 rows per cell (availability-starved: 1,289 "no_direct_local_negative_evidence", 3,150 "no_unentailed_category_without_negative_evidence", 1,173 "not_all_four_cells_available_at_all_positions" in `summary_tables.json`).
- **matched_pert.py matches on**: instance, prefix, injection point (mid), decoding distribution (T=0.8, n=4 for both perturbed and null), hidden-state alignment convention. Nothing lexical.

## 4. Minimal NEW conditions to close the matrix, with PrOntoQA-OOD constructibility

Why EXPC's strict local-positive cell degenerated: `make_local_false_positive` needs a direct rule from a prefix category to a **negative RHS**. In the corpus, `grep` over `data/prontoqa_ood/*ProofsOnly*.json` finds **zero** negative-category rules ("...are not X-puses") — negation appears only on terminal adjective properties ("...puses are not blue"). Negative-category rules DO exist in the `*Composed*` files (e.g., "…are not brimpuses", 10–30 hits per category, from ProofByContra/composed worlds), but they almost never sit exactly one hop from an early/mid/late prefix in a validator-valid, ≥3-intermediate proof, so the fail-closed 2×2×3 matching never surfaces a category-typed LFP. That is the binding constraint, not the audit logic.

Minimal set (6 conditions; a–c are the load-bearing ones):

1. **(a) LOCAL_FALSE_POSITIVE_CATEGORY** — inject `"{Entity} is a {c}."` where `"{prefix-cat}s are not {c}s"` is a stated rule one hop from the prefix. *Constructible?* **Marginal from raw data** (Composed-only, and the all-positions matching kills it); **cleanly constructible with world augmentation**: add one true disjointness rule `"Every {prefix-cat} is not a {c}."` to the *question* (validator's `parse_rule` already supports `not_cat` RHS, so audit/closure work unchanged). This is the rule-mediated (distance-1, non-lexical) counterpart of EXPB's distance-0 certificate — it separates "string contradiction" from "one-rule refutability", the residual confound EXPB leaves open. Cost: context differs by one sentence across arms → pair with a matched irrelevant disjointness rule control (EXPB pattern).
2. **(b) TRUE_INTERRUPTION_NEGATIVE** — inject a *true negated* statement, e.g., an entailed negative pred ("X is not bright." when entailed, or `"{Entity} is not a {c}."` for a Composed-world entailed not_cat) that is off the current path. Fills the true×negation cell, deconfounding "negation token → doubt/derail" from falsity. *Constructible?* **Yes** for adjective targets in ProofsOnly (every chain ending in a negative attribute entails one); category-typed version Composed-only. Audit already labels entailed negatives `true` (EXPB's `audit_truth_status` branch `negated_entailed_category`… note EXPA's version returns `false/unknown` here — use EXPB/EXPC semantics).
3. **(c) FALSE_RULE (distractor made auditable) + TRUE_RULE control** — (i) false rule contradicting a stated rule at controllable distance: `"Every {on-path cat} is {adj}."` when the question states `"{cat}s are not {adj}."` (locally refutable rule, R=0 lexical) and `"Every {cat_k} is a {false-cat}."` for the category the chain reaches k hops later (R=k); (ii) TRUE_RULE interruption = verbatim restatement of an actual off-path question rule. Crosses statement-type (rule vs fact) with falsity and R, isolating the distractor family's double confound. *Constructible?* **Textually trivial**; requires a small validator/audit extension (rules are currently "unparsed" by `parse_statement_for_audit`; define rule truth as: false iff closure entails the opposite RHS for the LHS category, else CWA-false/unknown — ~20 lines against existing `closure`).
4. **(d) NEGHOP-k with goal-distance stratification** — not a new template: report/refit neghop-k with covariate `hops-remaining-to-conclusion`, or subsample so k varies while goal distance is fixed (needs long Composed chains). Kills the R×goal-proximity confound in the dose-response. *Constructible?* Yes, data-analysis + instance filtering only.
5. **(e) PARAPHRASE decomposition** — two micro-controls: exact repetition (no marker) and marker-prefixed *global falsehood*. Separates "stylistic marker" and "step preserved vs deleted" from benignness; currently benign-vs-falsehood differs on 3 axes at once. *Constructible?* Trivially.
6. **(f) ON-PATH × POSITIVE × FALSE — record as structurally empty.** Any positive entity claim on the gold path is entailed, hence true; in this grammar the cell is logically unconstructible (only negations of on-path facts can be false). State this in the paper's confound-matrix table rather than leaving the cell blank — it converts a "missing experiment" into a grammar theorem, and it is the honest reason the local row of EXPC must use either attribute-typed positives (a) or certificate/world augmentation (EXPB, a).
