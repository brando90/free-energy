## 4. Design: grid per model (reduced EXPD core; generator/harness byte-identical)

Same world generator (`gen_worlds_expd.py`, reused unchanged), same fail-closed audits, same
injection protocol (each model perturbs its OWN gold rollouts; gold must be `solved`
∧ `valid_rederivation` ∧ injection-points-available — the EXPA double filter), same prompt
construction (INSTR+FEWSHOT, `prompt_sha256` published), greedy, max_new=192, wholly vLLM
(pinned lock), no cross-backend comparisons. Deviations from the full EXPD grid (disclosed,
cost-motivated): d=2 attribute cells dropped; true-attribute quartet reduced to one MC cell pair;
satellites dropped.

| Block | Cells | n target |
|---|---|---|
| Attribute false | `aff_false_attr`, `neg_false_attr` × d{0,1,3,5} × 3 pos | 150/cell/pos (3,600/model) |
| Categorical reuse | `cat_false_{usable,inert}` × d{1,3,∞} × {early,mid} | 150/cell/pos (1,800/model) |
| Anchors | `benign_paraphrase`, `true_interruption` × 3 pos | 150/cell/pos (900/model) |
| MC true cells | `aff_true_attr_d1`, `neg_true_attr_d1` @ mid | 150/cell (300/model) |

≈6,600 perturbed generations/model + per-model gold per the §3 oversample. All PLAN2 fail-closed
audits (measured d == designed d; truth-status; planted-token frequency; MOD-13 identical-prefix
cohort for the polarity contrast) apply unchanged.

**Oversampling mechanism (generator reused unchanged):** the EXPD full world config (2,880 worlds,
sized for Qwen-7B's ~0.90 eligibility) under-provisions weaker models. Extra worlds are obtained
by running the *unchanged* `gen_worlds_expd.generate_and_write(config="full")` under K distinct
seeds (K = the §3 oversample) and merging the shards under a per-shard `s{seed}_` id prefix +
`family_idx` offset so `world_id`/`family_id`/`partner_world_id` stay globally unique; each shard
is fail-closed audited independently before merge (any shard audit failure aborts). The generator
source is not edited. The per-cell cap (150 eligible worlds) is unchanged, so surplus worlds are
simply unused; the oversample only widens the eligible pool to absorb attrition.

## 6. THE confirmatory family — per-model boundary slots, Holm within model (m = 3), α = 0.05

Qwen2.5-7B anchors (for magnitude thresholds; NOT re-tested): d=0 cliff +0.209 [0.153, 0.264] (stated-comp 0.247 vs 0.031); usability gap ≈ +0.80 (usable 0.863/0.768/0.787 vs inert ≤0.023); flat-d stated-comp d1..d5 = 0.031/0.050/0.021.

Within each subject model Mi, Holm–Bonferroni over the three slots (conjunctive slots are intersection-union; no alpha splitting inside a slot). Cluster unit = family_id (mirrored-quadruple/base-chain), cluster-bootstrap CIs; primary contrasts pooled over positions.

| Slot | Boundary condition | Test | Passes iff |
|---|---|---|---|
| **B1** | d=0 cliff (sign + magnitude) | stated-complement(`aff_false_attr_d0`) − stated-complement(`aff_false_attr_d1`), one-sided > 0, cluster bootstrap | p < Holm-α **AND** point diff ≥ **+0.10** |
| **B2** | usability gap (sign + magnitude) | derivational inj-dep(`cat_false_usable`, pooled d{1,3,∞}) − (`cat_false_inert`, pooled), one-sided > 0 | p < Holm-α **AND** point diff ≥ **+0.30** |
| **B3** | flat-d (conjunctive TOST) | (i) stated-complement `aff_false_attr` d1 vs d5 TOST ±0.10; (ii) derivational inj-dep `cat_false_usable` d1 vs d∞ TOST ±0.15 | both TOSTs pass at the slot's Holm-α |

### 6.1 Decision rules (fixed now)

- **Model-level replication:** model Mi *fully replicates* iff B1 ∧ B2 ∧ B3 all pass under Mi's Holm family. Per-slot partial outcomes are reported per model regardless.
- **Program-level claim** ("the boundary conditions replicate across open-weights models"): iff **≥3 of the 4 scored models fully replicate** (§12.4 resolved: ≥3/4, absolute floor 3). The absolute floor of 3 fully-replicating models binds even if a model is excluded under §8 (denominator shrinks; the ≥3 count does not).
- **Per-condition claims** (e.g., "the d=0 cliff is general"): iff ≥3/4 of scored models pass that slot.
- **Pre-stated failure reading:** any model that FAILS B3 because it genuinely checks at d≥1 (stated-complement rising in d) is a *positive scientific finding* (a checking model), reported as such — it still counts as a non-replication for the claim rule. No re-framing of the claim rule post hoc.
- Every slot verdict is reported; no model or slot is dropped silently.

## 8. Exclusion rules (pre-stated)

1. **Row-level:** identical to EXPD (double filter on golds; fail-closed audit rejections counted, never patched).
2. **Cell-level:** target n=150/cell/pos after filtering. If a cell lands 100 ≤ n < 150: scored, flagged. If 50 ≤ n < 100: scored, CI-widened, flagged prominently. If n < 50: the affected slot for that model is **INVALID-underpowered** — reported, not scored, counts as "not replicating" for the program-level rule (conservative direction).
3. **Model-level:** a model is excluded from scoring (denominator shrinks per §6.1) iff, after its full gold oversample (§3), gold-eligible cohort < 25% of target, OR MC-R2 fails. Exclusion is disclosed with the funnel; no additional gold budget may be added post-commit except by dated addendum filed before that model's perturbed generation.
4. No hypothesis may be added/removed except by timestamped addendum before the affected model's first gold generation.

## 9. Power / n (from EXPD attrition data — no new power model invented)

- EXPD (7B): gold solve 0.935, joint-eligible pair rates 0.79–0.89, 2,880 gold attempts sufficed for n=150 everywhere. M1/M3 are ≥7B-class: 2× oversample is conservative.
- M2/M4 (OLMo-7B, Qwen-1.5B): expected gold solve substantially lower; **4× oversample** (per ICLR plan E1). At solve ≥ 0.25, 4× (11,520 worlds) still clears n=150/cell; below that, §8.3 governs.
- B1 at n=450/cell (3 pos pooled): detects diff ≥ 0.10 with power > 0.95 at Holm-α (two-proportion, baseline 0.03). B2 at n=600 vs 750+ pooled: power ≈ 1 for diff ≥ 0.30. B3 TOST at n≈450/cell: 90% CI half-width ≈ 0.05 vs ±0.10 margin — decisive; ±0.15 reuse margin at n=300/level similarly decisive.
- Compute: EXPD full grid was 0.09 GPU-h on one H200 (vLLM); 4 models ≈ <8 GPU-h total including golds. Engineering: 2–4 person-days QA.
